LoadNode
  Call through call_ktool with exactly this shape: {"name":"LoadNode","arguments":{"identifier":"Nl_hWdsl"}}. Replace the example identifier with the exact canonical eight-character identifier of the node. It loads or refreshes that node and the nearby fixed and fanout context that helps navigate from it. Repeated loads refresh existing boxes instead of duplicating them. A summarized or dehydrated box keeps that representation and becomes stale if the canonical node changed. There is no fixed LoadNode count; the active context budget is the limit.

DehydrateBox
  Give it the numeric boxId. It removes that box's substantive contents from active context while retaining its identity, lineage, revision, restoration metadata, and chronological continuation markers. This does not unload tool state or change canonical contents.

SummarizeBox
  Give it the numeric boxId and the exact summary text Kennedy wants to retain. It replaces the box's active representation with that summary. Canonical contents and lineage remain intact. If the owning tool later changes the canonical value, the summary remains visible and becomes stale.

HydrateBox
  Give it the numeric boxId. It restores the latest canonical contents of an active box without rerunning its owner. Hydration is rejected if the projected context would exceed the session's applicable limit.

HydrateEvent
  This is available only during history ingress. Give it the numeric eventId. It hydrates that exact persisted source event into an ingress inspection box. The dehydrated history skeleton reports approximate hydration costs.

DehydrateEvent
  This is available only during history ingress. Give it the numeric eventId. It retires the active inspection box for that previously hydrated source event. It does not mutate source history.

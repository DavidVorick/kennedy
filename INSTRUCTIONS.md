# Repository Instructions

All LLM agents that create commits in this repository must include their own model type, model version, and reasoning/thinking profile in every commit message.

Examples:

- `Add kweb API specification (GPT-5.5 medium)`
- `Update frontend prompt manuals (Claude Opus 4.8 xhigh)`

The model identifier must be included in the commit subject line so it is visible in normal `git log --oneline` output.
